I added a bunch of large blocklists and decided to consolidate them into one so it would be easier for anyone who wants it

If the button doesn't work, add it manually:

1. Open the uBlacklist settings.
2. Go down to **Subscriptions**.
3. Click **Add a Subscription**.
4. Paste this into the **URL** field:

```text
https://raw.githubusercontent.com/echocosm/echo-ublacklist/main/echo-ublacklist.txt
```

5. Leave the other two fields as they are.
6. Click **Add**.
